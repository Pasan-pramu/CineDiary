# CineDiary — Ideas

Notes for later versions. Items marked **(1.1.0)** are done or partly done in v1.1.0.

## Why logging is hard to find

- After adding a title there's no clear next step to log a watch.
  **(1.1.0)** "Have you watched it?" opens the right form after saving; the success screen has
  Start watching / Log a past watch.
- The Status dropdown looks like the place to log a watch, but saves no watch and no moods; a
  later Start watching on a "Completed" title becomes a rewatch.
  **(1.1.0)** Replaced by "Have you watched it?" in Add Title and Quick Add; Watching now and
  Already watched always save a real watch.
- Home, Journal and Timeline have no "Log a watch" button.
- "Finish & reflect" had a ⋮ icon that looked like a menu. **(1.1.0)** It has a check icon.
- Different words for the same thing: watch entry, memory, Journal, Watch history.
- Scores were optional, but mood change and Insights need them.
  **(1.1.0, partly)** Still optional, but picking a mood pre-selects a suggested score.

## Ideas for later

- A "Log a watch" item in the sidebar / Ctrl+N: pick a title, then the form opens. A Home card:
  "Watched something? Log how it felt".
- Finish and +1 episode buttons directly on Home's Currently watching.
- When a series reaches its last episode, ask "Finished? Reflect now".
- One name everywhere (e.g. "watch memory") and a first-run tip on the first title page.
- A fast "Add past movies" mode for many old movies in a row.
  **(1.1.0, partly)** "Save & add another past movie" after an Already watched title.
- Import from Letterboxd / IMDb CSV exports.
